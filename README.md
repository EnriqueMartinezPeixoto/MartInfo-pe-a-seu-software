# MartInfo – Peça seu Software 🚀
Formulário inteligente e dinâmico para captação de requisitos, orçamentos e pedidos de desenvolvimento de software, com integração direta para o WhatsApp.

Um formulário interativo, responsivo e de design moderno (Dark Mode/Tech) desenvolvido para facilitar a captação de pedidos de software, sites e aplicativos. O sistema coleta dados essenciais do cliente, como requisitos funcionais e não funcionais, orçamento, integrações e público-alvo, e gera um resumo organizado enviado diretamente via WhatsApp.

## ✨ Funcionalidades

- **Design Moderno:** Interface em Dark Mode focada em tecnologia, com tipografia limpa (Google Fonts: Inter e Outfit).
- **Campos Dinâmicos:** As opções do formulário se adaptam com base nas respostas do usuário (ex: revela campos específicos se o uso for para "Negócio", "Grupo" ou "Empresa").
- **Coleta de Cores:** Permite que o cliente escolha sua paleta de cores preferida através de um color picker nativo.
- **Integração com WhatsApp:** Processa todas as informações preenchidas e redireciona o cliente para o WhatsApp com uma mensagem estruturada e pronta para envio.
- **Cópia Rápida:** Botão alternativo para copiar o resumo do pedido diretamente para a área de transferência.
- **Validação de Dados:** Impede o envio se campos obrigatórios (nome, problema, tipo de projeto e uso) não forem preenchidos.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica.
- **CSS3:** Estilização com variáveis (`:root`), Flexbox, CSS Grid, responsividade nativa e interface moderna sem uso de frameworks externos.
- **JavaScript (Vanilla):** Lógica de manipulação do DOM, validação de formulário, formatação da mensagem e integração com a API de links do WhatsApp.
